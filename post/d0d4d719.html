我的世界服务器核心介绍

| 原作者：晓空ag | 改写者：无奈的程序员 |

前言

    1.如果在网上租服务器或许这些你不需要了解，如果你自己搭建服务器那就得需要好好的了解了解这些稀奇古怪的玩意儿。

一、介绍

1.每个 Minecraft 我的世界服务器核心版本适用的 Java 版本。

MC 版本 最低 Java 推荐 Java 适用核心 备注 Java
1.0 ~ 1.11.2 Java 8 Java 8 Vanilla、Bukkit、Spigot、Paper、Forge 老版本不要用 Java17+，大概率启动失败
1.12 ~ 1.16.4 Java 8 Java 8 / Java11 Vanilla、Bukkit、Spigot、Paper、Purpur、Forge、Fabric 1.12.2 Forge 模组强制 Java8，很多旧模组不支持高版本 Java
1.16.5 Java 8 Java11 / Java16 全部主流核心 Java8 可跑；Paper 推荐 Java11+；部分新插件需要 Java11
1.17 ~ 1.17.1 Java 16 Java16（可用 Java17） Vanilla、Spigot、Paper、Purpur、Forge、Fabric ❌ Java8 彻底不能用；Java17 可兼容但官方基准是 16
1.18 ~ 1.20.4 Java17 Java17 Vanilla、Spigot、Paper、Purpur、Forge、Fabric Mojang 强制 Java17；Paper 可在 Java21 运行，但官方基准 17
1.20.5 ~ 1.21.x Java21 Java21 Vanilla、Paper、Purpur、Fabric、NeoForge 强制 Java21，Java17 直接报错；Forge 1.20.5 + 改名 NeoForge
26.x Java25 Java25（LTS） Vanilla、Paper、Purpur、Spigot、Fabric、NeoForge ❌ Java21 及更低直接报错，官方内置 JDK 为 Microsoft OpenJDK25；默认 GC 改为 ZGC

2.Minecraft 我的世界服务器核心介绍。

a、原版/纯净版核心（无插件、无模组，Mojang 官方）

  1. Vanilla（原版服务端）【活跃】
    官网：https://www.minecraft.net/en-us/download/server
    简介：Mojang 官方原生服务端，纯净原版，仅命令方块 / 数据包，不支持插件

b、插件服核心（Bukkit/Spigot/Paper API，只装插件，不能直接装 mod）

  1. Spigot【活跃】
    官网：https://www.spigotmc.org/
    简介：Bukkit 后继，最老牌插件核心，使用 BuildTools.jar 编译构建
  2. Paper【活跃｜ PaperMC 团队】
    官网：https://papermc.io/
    简介：Spigot 分支，性能大幅优化，现在最主流插件服核心
  3. Folia【活跃｜ PaperMC 团队】
    官网：https://papermc.io/software/folia
    简介：Paper 衍生，多线程分区世界，超大服 / 巨型主城专用；很多插件不兼容
  4. Purpur【活跃｜ PurpurMC】
    官网：https://purpurmc.org/
    简介：基于 Paper，大量可自定义游戏玩法参数，Paper 插件直接兼容
  5. Pufferfish【活跃】
    官网：https://pufferfish.host/
    简介：Paper 高性能分支，侧重内存、GC 优化，适合高在线服务器
  6. Tuinity【停更归档】
    Github 主页：https://github.com/Tuinity/Tuinity
    简介：旧版 Paper 优化分支，项目并入 Pufferfish，不再更新
  7. Akarin（萤火）【停更归档】
    Github 主页：https://github.com/Akarin-project/Akarin
    简介：国内优化 Paper 分支，仅 1.12.2~1.15.2
  8. CraftBukkit【停更归档】
    官网：无独立下载站，只能 Spigot BuildTools 构建
    简介：Bukkit 官方实现，版权事件停止开发，API 被 Spigot/Paper 继承

c、模组服核心（只装 Mod，原生不支持 Bukkit 插件）

  1. Forge（旧版，1.20.4 及更早）【停止新版开发，1.20.5 起改名 NeoForge】
    官网：https://files.minecraftforge.net/
    简介：老牌模组加载器，大量旧科技 / 魔法模组依赖 Forge
  2. NeoForge（原 Forge 1.20.5+）【活跃】
    官网：https://neoforged.net/
    简介：Forge 团队拆分后的新项目，26.x 新版本强制使用 NeoForge
  3. Fabric【活跃】
    官网：https://fabricmc.net/
    简介：轻量模组加载器，更新快，大量轻量、优化类模组；需要 Fabric API
  4. Quilt【活跃】
    官网：https://quiltmc.org/
    简介：Fabric 分支，兼容大部分 Fabric 模组，扩展更多底层 API
  5. Sponge（SpongeVanilla / SpongeForge）【维护放缓】
    官网：https://www.spongepowered.org/
    简介：独立 API，可跑 Sponge 插件，SpongeForge 能同时加载 Forge Mod；生态较小

d、混合核心（同时支持 Mod + Bukkit/Paper 插件，模组服开插件首选）

  1. Mohist【旧 Forge 版 EOL；Youer 为 NeoForge 新版】
    官网：https://mohistmc.com/
    简介：Forge + Paper API 混合核心；Youer 是 Mohist 开发组的 NeoForge 新版混合端
  2. Arclight【活跃】
    官网：https://izzel.io/arclight
    简介：基于 Forge，原生支持 Bukkit 插件，高版本混合服常用
  3. CatServer【1.12.2 为主，新版本更新慢】
    官网：https://catserver.moe/
    简介：国内开发，1.12.2 最经典混合端，1.12.2 模组 + 插件首选，高版本支持弱

远古混合端（完全停更，仅历史遗留）：Cauldron、KCauldron、Thermos、MCPC+，这里不再赘述。

e、群组代理核心（Proxy，群组服，不加载世界，用来多服互联）

  1. Velocity【活跃｜ PaperMC 团队，现代首选】
    官网：https://papermc.io/software/velocity
    简介：新一代高性能代理，支持现代版本、Forge/Fabric 模组服互通
  2. BungeeCord【活跃维护，但老旧】
    官网：https://www.spigotmc.org/wiki/bungeecord/
    简介：经典老牌群组代理，1.8~1.14 旧群组服大量在用
  3. Waterfall【停更归档，Bungee 优化分支】
    Github：https://github.com/PaperMC/Waterfall
    简介：PaperMC 的 BungeeCord 增强版，现已停止维护，推荐换 Velocity

f、基岩版 Bedrock

  1. BDS Bedrock Dedicated Server（官方基岩服务端）
    官网：https://www.minecraft.net/en-us/download/server/bedrock
    简介：Mojang 官方 C++ 基岩服，Windows/Linux，支持行为包，原生无插件；搭配 LiteLoaderBDS 可加载插件
  2. NukkitX（第三方基岩 Java 服）
    官网：https://nukkitx.com/
    简介：支持较多玩家，PNX 分支很好；原版 NKX 差，大型服、小游戏、PNX 可做生存。
  3. BDS Bedrock Dedicated Server（官方基岩服务端）
    官网：https://www.minecraft.net/en-us/download/server/bedrock
    简介：适合中小服，上手简单，一键安装脚本，新手友好；插件数量极多，Poggit 社区海量小游戏、领地、权限、传送插件；PHP 性能上限低，不适合百人以上高在线，人多容易卡顿、内存暴涨；复杂生电、红石农场基本无法正常工作。

补充小提示

  1. 项目标注【停更】代表不再发布新版本，只能用历史旧版本，不推荐新服使用；
  2. 混合端稳定性普遍弱于纯插件 / 纯模组核心，大型模组服谨慎选用；
  3. 代理核心不是游戏服务端，只负责玩家转发，不能单独开世界。
